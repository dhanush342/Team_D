An end-to-end industrial machine-learning and process optimization prototype developed using the **AI4I 2020 Predictive Maintenance Dataset**. The system predicts machine failure risks from operating sensor telemetry, detects atypical statistical anomalies, compares 8 classification models, and provides physics-informed condition-based maintenance guidance.

---

## 📌 Key Highlights

- **8 Machine Learning Algorithms**: Evaluates Logistic Regression, Decision Tree, Random Forest, Extra Trees, Gradient Boosting, AdaBoost, XGBoost, and Isolation Forest.
- **Strict Target Leakage Mitigation**: Completely excludes post-failure diagnostic flags (`TWF`, `HDF`, `PWF`, `OSF`, `RNF`) and row indices (`UDI`, `Product ID`) from training inputs.
- **Physics-Informed Real-Time Engine**:
  - **Thermal Dissipation ($\Delta T$):** Monitors process-to-ambient temperature differential against the critical $8.6\,\text{K}$ dissipation threshold.
  - **Mechanical Spindle Power ($P$):** Computes active power ($P = 2\pi \cdot \frac{N}{60} \cdot \tau$) to identify motor overload/underload conditions ($3.0\text{--}9.0\,\text{kW}$).
  - **Cutting Tool Health:** Tracks active cutting wear against the $200\,\text{min}$ replacement boundary.
- **Interactive Multi-Model Consensus**: Run all supervised classifiers simultaneously to view voting consensus alongside individual model risk scores.
- **Fleet Batch Assessment**: Monitor multiple machines at once via built-in sample fleet evaluation or custom CSV telemetry upload.
- **Actionable Maintenance Guidance**: Translates model predictions and operational sensor readings into concrete maintenance recommendations.

## 📊 Dataset & Feature Engineering

The system uses the **AI4I 2020 Predictive Maintenance Dataset** (10,000 synthetic observations reflecting realistic milling machine telemetry).

### Input Features Used for Inference:
| Feature | Type | Description | Operating Range |
| :--- | :---: | :--- | :---: |
| **Type** | Categorical | Product quality variant (`L` = 50%, `M` = 30%, `H` = 20%) | L, M, H |
| **Air temperature [K]** | Continuous | Ambient workshop temperature | 295.3 – 304.5 K |
| **Process temperature [K]** | Continuous | Active machining process temperature | 305.7 – 313.8 K |
| **Rotational speed [rpm]** | Integer | Spindle rotational speed | 1,168 – 2,886 rpm |
| **Torque [Nm]** | Continuous | Torque applied by the spindle motor | 3.8 – 76.6 Nm |
| **Tool wear [min]** | Integer | Cumulative cutting time of current tool insert | 0 – 253 min |

### 🛡️ Why Target Leakage Prevention Matters:
The raw dataset contains failure-mode breakdown flags:
- `TWF`: Tool Wear Failure
- `HDF`: Heat Dissipation Failure
- `PWF`: Power Failure
- `OSF`: Overstrain Failure
- `RNF`: Random Failure

> **Architectural Decision:** These columns are recorded *after* a failure has already transpired. Including them as inputs produces artificial ~100% accuracy but renders the model completely useless for real-world advance prediction. They are strictly excluded from all training and inference pipelines.

## 🏆 Model Evaluation & Benchmarks

All models were evaluated on a **stratified 20% held-out test set (2,000 machines)** with imbalanced target weighting (`scale_pos_weight` & balanced class weights):

| Model | Accuracy | Precision | Recall | F1-Score | ROC-AUC | PR-AUC | Primary Strength |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :--- |
| **XGBoost** | 96.70% | 50.86% | **86.76%** | **0.6413** | **0.9748** | **0.8155** | 🏆 **Top Safety Model** (Highest Recall & PR-AUC) |
| **Decision Tree** | 95.10% | 39.58% | 83.82% | 0.5377 | 0.9090 | 0.7563 | High sensitivity, transparent decision rules |
| **Logistic Regression** | 82.45% | 14.18% | 82.35% | 0.2419 | 0.9070 | 0.3818 | Fast linear baseline with balanced weighting |
| **Extra Trees** | 96.75% | 51.61% | 70.59% | 0.5963 | 0.9581 | 0.6182 | Ensemble variance reduction |
| **Random Forest** | **98.30%** | **82.69%** | 63.24% | **0.7167** | 0.9610 | 0.7719 | 🎯 **Highest Accuracy & Precision** |
| **Gradient Boosting** | 97.70% | 80.56% | 42.65% | 0.5577 | 0.9602 | 0.6981 | Robust standard boosting |
| **AdaBoost** | 97.15% | 73.91% | 25.00% | 0.3736 | 0.9497 | 0.5565 | Adaptive sequential boosting |
| **Isolation Forest** | 94.20% | 13.64% | 13.24% | 0.1343 | 0.7424 | 0.0836 | 🔍 Unsupervised Outlier / Novelty Detector |

*Note: In industrial predictive maintenance, **Recall** is prioritized because the operational cost of missing a catastrophic machine breakdown far exceeds that of a false-positive inspection.*

## 🚀 Getting Started

### 1. Prerequisites & Virtual Environment

Clone the repository and create an isolated Python virtual environment:

```powershell
# Windows PowerShell
git clone https://github.com/your-username/AI-Based-Industrial-Maintenance.git
cd AI-Based-Industrial-Maintenance

python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### 2. Exploratory Data Analysis (EDA)

Inspect dataset summary statistics and generate the class distribution chart:

```powershell
python explore_data.py
```
*Output: Saves `reports/failure_distribution.png`.*

### 3. Model Training & Artifact Generation

Train all 8 models, calculate metrics, and save serialized pipelines:

```powershell
python train_model.py
```
*Outputs: Saves `models/failure_model.pkl`, `reports/model_metrics.csv`, `reports/model_comparison.png`, confusion matrix plots, and classification reports.*

### 4. Launch the Streamlit Dashboard

Start the local web application:

```powershell
python -m streamlit run app.py
```

Open your browser and navigate to **`http://localhost:8501`**.

## 🖥️ Dashboard Features

The Streamlit interface offers 5 dedicated modules:

1. **⚡ Live Machine Diagnostics**:
   - Parameter inputs with real-time domain physics indicators ($\Delta T$, Motor Power $P$, Tool Wear status).
   - 5 Quick-fill presets: *Normal Operation*, *Tool Wear Stress*, *Overheating Risk*, *Power Overload*, *Heavy Overstrain*.
   - Plotly Radial Gauge Meter displaying failure probability with dynamic color coding.
   - Cross-model consensus mode comparing all 7 classifiers simultaneously.
   - Rule-based condition maintenance advisory alerts.
2. **📊 Model Benchmarks & Reports**:
   - Top performer highlight cards (Best Recall, Best F1, Best Accuracy).
   - Interactive ranking bar charts filtered by selected metric.
   - High-resolution confusion matrix images and classification report text viewer.
3. **📁 Batch Fleet Prediction**:
   - Evaluate a 25-machine sample fleet or upload a custom CSV file.
   - View summary KPIs (Flagged Machines, Nominal Operations) and download annotated CSV reports.
4. **🔍 Dataset & Leakage Analysis**:
   - Overview of class imbalance (96.6% normal vs 3.4% failure).
   - Methodology breakdown of target leakage prevention.
5. **📘 Architecture & Guidance**:
   - ML pipeline architecture flowchart and industrial safety standard operating procedures.
